# BOOTSTRAP
**BOOTSTRAP** is **UNMODDABLE**'s core - the mod loader itself.

It loads mods.

The more you know

This is a same thing what mod launchers (like Nexus, Thunderstore and Archipelago) put into your game automatically.

# How to install BOOTSTRAP
1. Find where **UNBEATABLE** is (all caps or not caps).
    1. Go to **Steam** -> **Right click the game** in the games list.
    2. Navigate to **Properties...** -> **Installed Files** -> **Browse...**
    - This is where mod loader (without the mods) will be placed.
2. Put following files next to `UNBEATABLE.exe`:
    1. `.doorstop_version`.
    2. `dootstop_config.ini`
    3. `winhttp.dll`
    4. entire `BOOTSTRAP` folder.
3. **Mods will now load automatically!**

4. Testing installation:
    1. Launch the game, and enter main menu.
    2. `unmoddable.log` should appear next to `UNBEATABLE.exe`.

Now, follow `UNMODDABLE`'s guide to install actual mods.
